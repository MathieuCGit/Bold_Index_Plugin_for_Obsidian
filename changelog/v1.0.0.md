# Changelog - v1.0.0

**Release Date:** August 14, 2026

---

## 🎉 Initial Release

Navigation Index for Obsidian is officially released with comprehensive markdown indexing and navigation capabilities.

---

## ✨ Features

### Core Functionality

- **📑 Multi-Format Index** - Scan notes for bold (`**text**`), italic (`*text*` / `_text_`), and highlight (`==text==`) formatting simultaneously
- **🎯 Interactive Sidebar Panel** - Display formatted terms in a compact, organized sidebar view
- **📍 One-Click Navigation** - Click line numbers to jump directly to terms in your note, with automatic text selection
- **🔍 Live Search Filter** - Real-time search with case-insensitive partial matching
- **📊 Smart Sorting** - Two sorting modes:
  - Alphabetical ordering (default) using French locale for natural results
  - Document order (by line number) for reading sequence
- **📤 Markdown Export** - Save index as standalone markdown file alongside your note
- **🛡️ Code Protection** - Automatically ignores formatted text in code blocks and inline code
- **🔄 Cumulative Format Selection** - Toggle B, I, H buttons independently; combine any mix
- **⚙️ Persistent Preferences** - Remember selected format modes and sort order across sessions

### User Interface

- Compact toolbar with format mode buttons (B, I, H)
- Dropdown sort menu with visual selection indicator
- Live search input with instant filtering
- Clickable entry list with line number references
- Deduplication for cleaner display (one line per term per line)
- Responsive design that adapts to any workspace layout

### Export Features

- **Export Button** - Generate markdown index file
- **Open Button** - Quickly view exported file in new editor tab
- Organized file naming (`{note-name}_index.md`)
- Preserves exact term names and line numbers

## 🔧 Technical Improvements

### Domain Layer (Parsing & Logic)

- **buildBoldIndex()** - Parse markdown and extract formatted terms
  - Handles multiple emphasis styles simultaneously
  - Groups repeated terms by occurrence
  - Deduplicates entries per line
  - Maintains line number tracking for navigation
  - Code-aware filtering (ignores code blocks and inline code)

- **filterBoldIndexEntries()** - Real-time search functionality
  - Case-insensitive matching
  - Partial term matching
  - Instant results without rebuilding index

- **sortBoldIndexEntries()** - Smart sorting with two modes
  - Alphabetical: French locale-aware natural ordering
  - ByLine: Groups entries by first occurrence line number
  - Defensive fallback to alphabetical if invalid mode supplied

- **buildMarkdownIndexDocument()** - Export formatting
  - Clean markdown bullet list format
  - Preserves all line number information
  - Includes note title in generated document

### Application Layer (Controller)

- **IndexController** - State management and coordination
  - Manages active format modes and sort preference
  - Handles file reading and index building
  - Wires callbacks between view and domain logic
  - Persists user preferences across sessions

### UI Layer (View)

- **IndexView** - DOM rendering and event handling
  - Creates sidebar panel structure
  - Renders format mode toggle buttons with visual feedback
  - Implements sort dropdown menu with hover effects
  - Handles live search input and real-time filtering
  - Creates clickable term list with line references
  - Manages navigation callbacks to editor

### Architecture

- **Separation of Concerns** - Domain logic independent from UI and Obsidian APIs
- **Testability** - Pure functions with no side effects enable comprehensive testing
- **Modularity** - Easy to extend with new format modes, sort types, or export formats
- **Performance** - Real-time updates without full index rebuilds on every keystroke

## 🐛 Known Limitations

- Works only on currently active note
- Does not index notes in attachments or external files
- Index updates only when note is opened or edited
- Sort preference is not persisted to disk (resets on session restart)

---

## 🚀 Performance

- Parses notes in real-time with minimal overhead
- Deferred re-renders prevent UI blocking on large notes
- Efficient code block detection and filtering
- Fast search filtering without index rebuild
